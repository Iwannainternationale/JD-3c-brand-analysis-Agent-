# 原版 Excel 月度市占看板

`marketshare_app.html` 与提供的原版压缩包中的同名 HTML 逐字节一致。它是可执行的独立页面，不依赖原仓库模板才能打开。本联合包没有打入原压缩包中的历史数据文件，也没有打入真实数据的导出产物；原 HTML 内的品牌映射、页面文字和第三方声明均保留。

## 试用

1. 完整解压，使用 Chrome 或 Edge 普通窗口打开 `marketshare_app.html`。
2. 在原始 Excel 导入区同时选中 `../examples/dashboard-excel/` 中的自营和 POP 两份样例（也可拖入）。
3. 等待装配，点「装配并查看看板」。模拟表覆盖 22 个月、16 个品牌、10 个兼容类目和 4 个渠道。

样例与风险联动演示使用同一组合成月度金额和标准品牌；本页的类目名称按原看板支持的类别做了映射。原版不会直接导入风险清单，若要体验 JSON 跳转，请用 `../dashboard/index.html`。周市占、经营数据和月度成交数据是不同口径，月表只提供排查背景。

## 自带底数的工作簿

工作簿使用 `数据` 工作表，首行至少需要 `时间`、`渠道`、`三级品类`、`标准品牌`、`销售额`；京东货盘拆分还使用 `货盘类型`。时间形如 `2026年9月`。`筛选条件` 工作表记录导出时间范围、经营模式（分别为 `自营` 和 `POP`）以及口径指纹。用示例表做结构参考，老版只识别既有渠道和类目。建议先上传**同口径、不重叠月份**的两张表，不把重复的月份当增量追加。

原版把导入结果保存在浏览器的 IndexedDB 中。若本地 HTML 的存储因浏览器环境不可用，建议先试普通窗口，并避免在 ZIP 或内嵌预览中直接打开。若仍失败，可以从仓库根目录运行 `python -m http.server 8765 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8765/marketshare_app/marketshare_app.html`；这个命令只在本机提供静态文件，Excel 仍由浏览器解析。此用法只用于试用，**不要把有真实输入、报告或备份的目录对外提供**。不必为排查问题清除浏览器数据。

「下载离线看板」和「导出底座文件」会携带装配结果或导入明细。处理真实 Excel 后，请把这些产物保存在仓库外，不要发到 GitHub。原版 HTML 的品牌映射可通过源码查看；公开前需确认原版代码和映射的分发许可。
